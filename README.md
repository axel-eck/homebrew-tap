# Axel-eck Tap

## How do I install these formulae?

`brew install axel-eck/tap/<formula>`

Or `brew tap axel-eck/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "axel-eck/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
